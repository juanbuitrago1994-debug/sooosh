# Despliegue (Vercel, São Paulo)

- **URL de producción**: https://sooosh.vercel.app · proyecto `sooosh` en el equipo «PapiJuanxxxo's projects» (plan Hobby), conectado a `juanbuitrago1994-debug/sooosh`: **cada `git push` a `main` despliega solo a producción**.
- **Región de las funciones**: `gru1` (São Paulo), fijada en `vercel.json`, junto a la base de Supabase (`sa-east-1`). Se comprueba con la cabecera `x-vercel-id` (`iad1::gru1::…`: entra por el borde de EE. UU. y ejecuta en São Paulo).
- **Variables de producción** (se cargaron con la CLI, sin pasar por el chat; las secretas quedan ocultas): `DATABASE_URL`, `SUPABASE_SECRET_KEY`, `ADMIN_TOKEN`, `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, `AUTH_DEVICE_SECRET` (**distinto del de local**: las sesiones de un lado no valen en el otro) y `ENABLE_EXPERIMENTAL_COREPACK=1` (el proyecto fija `pnpm@12`). No hay `OLLAMA_*`: **la IA es solo local** (decisión de Juan, 26-nov-2026).
- **Qué funciona en producción**: login con Google, registro, Ajustes, buscador, detalle de oferta, «Mis ofertas», alertas y notificaciones, exportar/borrar la cuenta. **Qué no**: leer un CV nuevo y analizar/adaptar ofertas con Ollama (esas rutas responden el error «Falta OLLAMA_URL…»); se hacen desde `localhost:3000` en el Mac.
- **Pendiente de Juan para poder entrar con Google en producción** (configuración que solo él puede tocar): (1) Supabase → Authentication → URL Configuration → «Redirect URLs»: añadir `https://sooosh.vercel.app/**` (mantener `http://localhost:3000/**`); (2) Google Cloud → el cliente OAuth → «Orígenes autorizados de JavaScript»: añadir `https://sooosh.vercel.app`. La URI de redirección de Google (`…supabase.co/auth/v1/callback`) no cambia.
- **Redesplegar a mano**: `npx vercel@latest deploy --prod --yes` desde la carpeta del proyecto (con la sesión de la CLI iniciada). Cambiar una variable: `npx vercel@latest env add NOMBRE production` (y redesplegar).
- **Límites del plan Hobby**: una sola región de funciones, funciones de hasta 60 s, sin registro de errores de más de 1 hora.
